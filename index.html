Set up this device to search

To start a search from this page, the page needs a key from GitHub. You do this once on each phone, iPad or PC. It takes about two minutes.

  1. Tap Get a key from GitHub. GitHub opens with the name, time limit and permission already filled in. Log in if it asks.
  2. Under Repository access, choose Only select repositories and pick omas-next-place.
  3. Scroll down, tap Generate token, then copy the key it shows you (it starts with github_pat_).
  4. Come back to this page, paste the key below and tap Save and search.
